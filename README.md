# Executive Financial Intelligence Dashboard (Power BI)

## 📌 Project Overview
Designed and deployed a modern financial reporting dashboard built within Power BI for C-suite executive performance analysis. The project translates raw, tabular sub-ledgers into responsive KPI tracking layers.

## 🛠️ Architecture & Technical Features
- **Visual Presentation Tool:** Power BI Desktop / Service Cloud Architecture
- **Modeling Engine:** Star Schema Modeling Layout featuring isolated Dimension Tables (`Dim_Vendors`, `Calendar_Master`) mapped to Transaction Fact files.
- **Languages Utilized:** DAX (Data Analysis Expressions) for complex time-intelligence analytics.

## 📉 Visual Interface Features
- **Drill-Through Performance Matrices:** Allows directors to look at the macro group view and drill directly into underlying department line-items.
- **Dynamic Filter Slicing:** Responsive structural filters mapping historical timeline trends, budget boundaries, and risk classifications instantly.
